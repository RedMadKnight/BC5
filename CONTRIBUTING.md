# Contributing to BC5

BC5 is an interoperability research project with an explicit anti-piracy stance. No Sony material is ever accepted here: no firmware, system modules, keys, SDK headers, `.self`/`.prx` files from a console, game dumps, `.ffpfsc` containers of real games, decrypted binaries, or links to any of these. We never download, search for or link to game dumps, torrents, warez sites or "backports", and the leaked PS5 BootROM keys are off-limits — we do not fetch, reproduce or reason from them. Test data is synthetic (generated by our own fixture code) or comes from open-source homebrew. Pull requests or issues that contain or point to such material will be closed and removed.

Every register name, packet layout and hardware fact must cite a source: a public repository file (path + commit), a public AMD document (name + section), or an experiment log under `experiments/`; unsourced claims go in a `TODO(verify):` comment, not in the docs as fact. Anything that submits to `amdgpu` must sit behind an explicit `--submit` flag that defaults to off and never runs in CI or tests, because a bad submission can reset the whole machine. Talk before coding: open an issue describing the experiment you want to run and what result would settle it, keep commits small with conventional messages, and license your contribution under GPL-2.0.
